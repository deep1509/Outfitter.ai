# Outfitter.ai Stage-1

Minimal backend-heavy prototype for an agentic shopping assistant. Uses public Shopify data to suggest products and build cart permalinks.

## Development

```bash
pnpm install
pnpm dev
```

### Testing

```bash
pnpm test
```

## Notes
- Only public endpoints are used. Respect merchants' terms of service and robots.txt.
- This prototype does not place orders or process payments.
